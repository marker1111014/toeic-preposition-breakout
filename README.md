# TOEIC Preposition Arcade（多益介係詞雙模式特訓：打磚塊 ＆ 防衛槍戰）

將多益（TOEIC）高頻「動詞／片語 × 介係詞」搭配製作成**雙模式互動複習遊戲（彈珠打磚塊 ＋ 防衛槍戰）**的純前端網頁專案（零外部套件依賴，單一 `index.html` 即可在瀏覽器、GitHub Pages 或 Cloudflare Workers 直接遊玩）。

---

## 為什麼改良傳統背誦遊戲？（學習科學與介面設計）

傳統遊戲直接套用在背單字時，容易出現「手眼忙著接球而無意識亂撞（缺乏主動回想）」與「眼睛盯著擋板導致沒看右側正解（分散注意力效應）」。本專案針對學習痛點與畫面體驗進行五大設計：

1. **雙遊戲玩法自由切換**：
   - **彈珠打磚塊（Breakout）**：
     - **瞄準思考模式（預設推薦）**：球回到擋板時自動吸附停球，讓學習者先讀懂磚塊上的動詞與中文語意、切換正確介係詞球，再沿著含牆面反彈預覽的雷射線瞄準發射；反彈回程時自動穿透避免無辜誤觸。
     - **街機連彈模式**：經典高速連續反彈玩法，飛行中可用 `1–9` 鍵或滑鼠滾輪即時切換介係詞球。
   - **防衛槍戰（Gun Battle）**：
     - 題目卡片化為敵機從上方 4 條獨立軌道緩慢垂降（可調 **慢速 / 標準 / 極速**，卡片底部附靠近防線危急進度條）。
     - 底部砲台可隨滑鼠瞄準發射對應介係詞子彈；若敵機突破防線將扣除 1 點護盾並記錄錯題，同時將該題重新排入佇列確保每題都練習到。
2. **原生 DOM ＋ 1:1 HiDPI Canvas 混合高解析畫面**：
   - 題目卡片與場內浮動文法解析採用瀏覽器原生 DOM 渲染，結合 `ResizeObserver` 與 `devicePixelRatio` 1:1 像素同步繪製砲台、雷射線與粒子，確保任何縮放與高解析螢幕皆清晰銳利。
3. **每局重開保證隨機洗牌**：
   - Lv.1–Lv.4（含 Lv.2 多義對照組）與錯題特訓局在每次進入或點擊「重開本關」時，皆強制產生與上一局不同的題目順序，避免記位置不記搭配。
4. **場內即時浮動提示 + 聽覺雙通道**：擊中正確目標時，於撞擊點原地跳出綠色 `✓ 完整片語 + 中文釋義`，並以 Web Speech API 自動朗讀片語或例句；誤選則震動目標卡片並顯示針對性的文法解析。
5. **同動詞多義對照（Lv.2）、零介係詞 `Ø` 陷阱（Lv.4）與右側複習筆記**：即時收錄已配對片語、中文解釋與商務例句（可點擊單卡重聽發音），並自動彙整錯題支援一鍵開啟「錯題特訓局」。

## 操作方式

- **切換介係詞球／子彈**：點擊下方按鈕列、按數字鍵 `1–9`、`Q` / `E` 上下切換，或在畫布上滾動滑鼠滾輪
- **移動擋板／砲台**：`A` / `D` 或 `←` / `→`（打磚塊街機模式或砲台防線區域亦可直接以滑鼠左右移動）
- **瞄準與發射／射擊**：在畫布上移動滑鼠對準目標磚塊或掉落題目，點擊滑鼠左鍵或按 `Space` 發射
- **語音與主題設定**：頂部按鈕可切換「朗讀片語 / 朗讀完整例句 / 靜音」、音效開關與深色／淺色主題

## 題庫分級與資料來源說明（4 關 × 12 題 = 48 題）

| 關卡 | 主題 | 目標分數帶 | 設計重點 |
| :--- | :--- | :--- | :--- |
| **Lv.1** | 核心固定搭配 | 450–600 分 | `comply with`、`abide by`、`refrain from` 等高頻單一介係詞語塊 |
| **Lv.2** | 同動詞多義對照組 | 600–750 分 | `apply`、`look`、`result`、`agree`、`consist` 依語意切換不同介係詞 |
| **Lv.3** | 進階商業與受詞夾心 | 750–900 分 | `attribute A to B`、`deprive A of B`、`prevent A from V-ing`（含干擾球） |
| **Lv.4** | 及物動詞零介係詞陷阱 | 衝刺 900+ 分 | 6 個 `Ø` 陷阱（`discuss / contact / attend / await / reach / emphasize`）混搭 6 個近義真介係詞（含干擾球 `about`） |

### 資料來源與可靠程度
- **詞彙高頻基準**：動詞本體參照 Browne & Culligan (2016) 發布之 **TOEIC Service List (TSL v1.2)**（150 萬字多益備考語料、1,250 核心詞表）。
- **搭配文法基準**：參照 Gardner & Davies (2007) 之 BNC 語料庫高頻片語動詞研究與英語教學標準 **Dependent Prepositions（依存介係詞）** 規範，並對齊 ETS 公開樣題（Part 5/6/3–4）常見職場情境。
- **誠實揭露與限制**：ETS 官方未公布完整歷屆真題片語詞頻統計，因此 Lv.1–Lv.4 的分層屬**以語料庫高頻字為基礎之教學經驗編排**，非官方出題百分比。語言搭配與例句之文法正確性經人工逐題歧義排查（每題題幹均透過受詞或括號中文鎖定唯一正解）。

## 本地執行或部署

- **本地遊玩**：直接以現代瀏覽器開啟 [`index.html`](./index.html) 即可（支援離線運作，所有題庫已內嵌，同時另附 [`data/toeic_preposition_bank.json`](./data/toeic_preposition_bank.json) 供資料檢視或擴充使用）。
- **Cloudflare Workers（單檔複製貼上免 CLI）**：
  1. 打開 [`worker.js`](./worker.js)（點 GitHub 右上角 **Copy raw file** 或 **Raw** 全選複製）。
  2. 前往 Cloudflare Dashboard → **Workers & Pages → Create → Start with Hello World! → Edit code**。
  3. 清空預設程式碼、貼上 `worker.js` 內容並點擊 **Deploy** 即可直接透過 `*.workers.dev` 遊玩。
- **GitHub Pages**：至 Repository `Settings → Pages`，將 Source 設為 `Deploy from a branch`（`main` / `/ (root)`）即可生成線上遊玩網址。
