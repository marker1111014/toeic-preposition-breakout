# TOEIC Preposition Breakout（多益介係詞彈珠打磚塊）

將多益（TOEIC）高頻「動詞／片語 × 介係詞」搭配製作成**彈球打磚塊（Breakout）互動複習遊戲**的純前端網頁專案（零外部套件依賴，單一 `index.html` 即可在瀏覽器或 GitHub Pages 直接遊玩）。

---

## 為什麼改良傳統打磚塊？（學習科學設計）

傳統打磚塊直接套用在背單字時，容易出現「手眼忙著接球而無意識亂撞（缺乏主動回想）」與「眼睛盯著擋板導致沒看右側正解（分散注意力效應）」。本原型針對這四項學習痛點進行改良：

1. **雙模式切換**：
   - **瞄準思考模式（預設推薦）**：球回到擋板時自動吸附停球，讓學習者先讀懂磚塊上的動詞與中文語意、切換正確介係詞球，再沿著含牆面反彈預覽的雷射線瞄準發射；反彈回程時自動穿透避免無辜誤觸。
   - **街機連彈模式**：經典高速連續反彈玩法，飛行中可用 `1–9` 鍵或滑鼠滾輪即時切換介係詞球。
2. **場內即時浮動提示 + 聽覺雙通道**：擊中正確磚塊時，於撞擊點原地跳出綠色 `✓ 完整片語 + 中文釋義`，並以 Web Speech API 自動朗讀片語或例句；撞錯則震動磚塊並顯示針對性的文法解析。
3. **同動詞多義對照組（Lv.2）與及物動詞「零介係詞 `Ø`」陷阱（Lv.4）**：專門針對華語考生常見失分點（如 `apply for` vs. `apply to`、`result in` vs. `result from`、`discuss` 不加 `about`、`await` 不加 `for`、`contact` 作動詞不加 `with`）。
4. **右側複習筆記 & 錯題特訓局**：即時收錄已配對片語、中文解釋與商務例句（可點擊單卡重聽發音），並自動彙整錯題，支援一鍵開啟「錯題特訓局」。

## 操作方式

- **切換介係詞球**：點擊下方球列、按數字鍵 `1–9`，或在畫布上滾動滑鼠滾輪
- **移動擋板**：`A` / `D` 或 `←` / `→`（街機模式亦可直接以滑鼠左右移動）
- **瞄準與發射**（瞄準思考模式）：移動滑鼠對準目標磚塊，點擊滑鼠左鍵或按 `Space` 發射
- **語音設定**：頂部按鈕可切換「朗讀片語 / 朗讀完整例句 / 靜音」

## 題庫分級與資料來源說明（4 關 × 12 題 = 48 題）

| 關卡 | 主題 | 目標分數帶 | 設計重點 |
| :--- | :--- | :--- | :--- |
| **Lv.1** | 核心固定搭配 | 450–600 分 | `comply with`、`abide by`、`refrain from` 等高頻單一介係詞語塊 |
| **Lv.2** | 同動詞多義對照組 | 600–750 分 | `apply`、`look`、`result`、`agree`、`consist` 依語意切換不同介係詞 |
| **Lv.3** | 進階商業與受詞夾心 | 750–900 分 | `attribute A to B`、`deprive A of B`、`prevent A from V-ing`（含干擾球） |
| **Lv.4** | 及物動詞零介係詞陷阱 | 衝刺 900+ 分 | 6 個 `Ø` 陷阱（`discuss / contact / attend / await / reach / emphasize`）混搭 6 個近義真介係詞（含干擾球 `about`） |

### 資料來源與可靠程度
- **詞彙高頻基準**：動詞本體參照 Browne & Culligan (2016) 發布之 **TOEIC Service List (TSL v1.2)**（150 萬字多益備考語料、1,250 核心詞表）。
- **搭配文法基準**：參照 Gardner & Davies (2007) 之 BNC 語料庫高頻片語動詞研究與英語教學標準 **Dependent Prepositions（依存介係詞）** 規範，並對齊 ETS 公開樣題（Part 5/6/3–4）常見職場情境。
- **誠實揭露與限制**：ETS 官方未公布完整歷屆真題片語詞頻統計，因此 Lv.1–Lv.4 的分層屬**以語料庫高頻字為基礎之教學經驗編排**，非官方出題百分比。語言搭配與例句之文法正確性經人工逐題歧義排查（每題題幹均透過受詞或括號中文鎖定唯一正解）。

## 本地執行或部署

- **本地遊玩**：直接以現代瀏覽器開啟 [`index.html`](./index.html) 即可（支援離線運作，所有題庫已內嵌，同時另附 [`data/toeic_preposition_bank.json`](./data/toeic_preposition_bank.json) 供資料檢視或擴充使用）。
- **GitHub Pages**：至 Repository `Settings → Pages`，將 Source 設為 `Deploy from a branch`（`main` / `/ (root)`）即可生成線上遊玩網址。
